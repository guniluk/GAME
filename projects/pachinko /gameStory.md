# 🍒 CHERRY MASTER '96 SPECIAL (8-Liner Slot Machine)
## 게임 종합 기획·설계 및 개발 구현 명세서 (Game Specification & Architecture)

본 문서는 정통 8-Liner 3x3 클래식 아케이드 비디오 슬롯 머신 **'체리 마스터 96 스페셜 (Cherry Master '96 Special)'**의 전체 게임 규칙, 심볼 배당, 보너스 메커니즘, 5단계 포커 더블찬스 시스템, 릴 물리 엔진, 조작법 및 데이터 구조를 총망라하여 정리한 단일 진실 공급원(Single Source of Truth) 명세서입니다.

---

## 1. 🕹️ 게임 개요 및 핵심 아키텍처

- **게임 장르**: 3행 3열 (3x3, 총 9칸) 8-Liner 클래식 아케이드 비디오 슬롯 머신
- **실행 환경**: HTML5 Canvas (60FPS 하드웨어 가속) + Vanilla JavaScript (ES6+) + Web Audio API
- **기본 통화/단위**: 크레딧 (Credit / $)
- **플레이 방식**: 코인을 투입한 후 1~8개 유효 라인을 설정하여 스핀을 시작하고, 약 3초 동안 시원하게 회전한 릴이 순차 감속 정지하여 형성된 라인 및 스캐터 배당에 따라 상금을 획득합니다. 당첨금 획득 시 **5단계 포커 카드 더블찬스(High-Low Double Up)**에 도전하여 최대 32배까지 상금을 불릴 수 있습니다.
- **핵심 특징**:
  1. **워터폴(Waterfall) 릴 물리 엔진**: 심볼들이 위에서 아래로 흐르는 실제 릴 스트립 스크롤과 3차 감속(Cubic Ease-Out) 정지로 끊김 없는 100% 매끄러운 60fps 회전-안착 렌더링.
  2. **순수 3x3 릴 그리드 & 1:1 단일 이미지 정렬**: 정지 시 9개 각 칸의 정중앙에 정확히 단 하나의 완성된 심볼 이미지만 깔끔하게 배치.
  3. **좌측 보너스 패널 보드**: 체리 5칸 램프 게이지, 종/BAR/777/ALL FRUITS 보너스 상태를 한눈에 파악하는 아케이드 대시보드.
  4. **모달 분리형 상세 배당표 (`[P] PAYTABLE`)**: 초대형 릴 화면을 유지하면서 언제든 키/버튼으로 상세 배당표 확인 가능.
  5. **5단계 포커 카드 더블찬스 (`HIGH & LOW`)**: 52장 포커 카드를 활용하여 5단계(2x ~ 32x)에 걸쳐 스테이지 그림이 레벨업되는 긴장감 넘치는 더블업 미니게임.
  6. **로컬스토리지 영구 저장 (Persistence)**: 크레딧, 체리 게이지 카운트, 누적 획득 상금 등이 브라우저에 안전하게 보존되어 언제든 이어하기 지원.

## 2. 🖥️ 화면 레이아웃 및 릴(Reel) 구조

### 2.1 3x3 릴 그리드 인덱스 (총 9칸)
```text
┌─────────────────┬─────────────────┬─────────────────┐
│   [0] (Row 0)   │   [1] (Row 0)   │   [2] (Row 0)   │  <- Top Row (상단)
├─────────────────┼─────────────────┼─────────────────┤
│   [3] (Row 1)   │   [4] (Row 1)   │   [5] (Row 1)   │  <- Center Row (중앙)
├─────────────────┼─────────────────┼─────────────────┤
│   [6] (Row 2)   │   [7] (Row 2)   │   [8] (Row 2)   │  <- Bottom Row (하단)
└─────────────────┴─────────────────┴─────────────────┘
      Reel 1            Reel 2            Reel 3
      (Col 0)           (Col 1)           (Col 2)
```

### 3.2 체리 (Cherry) 당첨 및 누적 게이지 규칙

체리는 **(1) 위치 당첨**, **(2) 2개 라인 완성 시 게이지 적립**, **(3) 3개 일치 시 즉시 보너스** 룰을 가집니다.

1. **체리 라인/위치 당첨금 (1열 또는 1행 시작점에서 연속 등장 시)**:
   - **체리 1개**: **$1** (점수만 획득, 게이지 미적립 ❌)
   - **체리 2개 라인 연결**: **$3** (점수 획득 + **체리 5회 게이지 1회 카운트 적립 ✅**)
   - **체리 3개 라인 일치**: **$5** (점수 획득 + **1회 무료 자동 보너스 롤 즉시 발동 🎁**)
2. **체리 5회 누적 빅보너스 (Cherry Big Bonus)**:
   - 체리 2개 라인이 **총 5회 누적**되어 게이지(5/5)가 완충되면 **체리 빅보너스(5회 무료 자동 스핀)**가 자동 발동하며, 발동 후 게이지는 0으로 리셋됩니다.

### 3.3 7 & 777 라인 혼합 당첨 및 위치 무관 스캐터(Scatter) 룰

7과 777은 체리마스터의 최고 가치를 지닌 심볼로, **라인 일치**와 **스캐터 당첨**을 모두 지원합니다.

#### A. 7 & 777 라인 일치 (혼합 가능 + 1회 보너스 발동)
7과 777이 섞여서 라인을 완성해도 당첨으로 인정되며, 777의 개수에 비례하여 가점됩니다. **모든 7 계열 라인 일치 시 1회 무료 자동 보너스 롤이 발동**합니다:
- **7 - 7 - 7 (순수 7 세 개)**: **$500 + 1회 보너스 롤**
- **7 - 7 - 777 (777 1개 포함)**: **$580 + 1회 보너스 롤**
- **7 - 777 - 777 (777 2개 포함)**: **$660 + 1회 보너스 롤**
- **777 - 777 - 777 (순수 777 세 개)**: **$750 + 1회 보너스 롤**

#### B. 7 & 777 스캐터 당첨 (라인 무관 화면 전체 2개 이상 등장 시)
라인을 이루지 않아도 화면 전체 9칸 중 7/777이 섞여서 2개 이상 등장하면 스캐터 점수를 획득하며, 777 개수당 추가 가점이 붙습니다:
- **2개**: 기본 **$50** (+777 개당 **$30**)

- **4개**: 기본 **$300** (+777 개당 **$80**)
- **5개**: 기본 **$500** (+777 개당 **$100**)
- **6개**: 기본 **$800** (+777 개당 **$150**)
- **7개**: 기본 **$1,200** (+777 개당 **$200**)
- **8개**: 기본 **$2,000** (+777 개당 **$300**)

### 3.4 🍓 ALL FRUITS (올 과일 특수 보너스)

## 4. 🎲 보너스 발생 빈도 순위 및 동적 확률 지터 (Jitter)

실제 아케이드 기판의 긴장감과 스릴을 위해 보너스 출현 빈도가 엄격하게 튜닝되어 있으며, 매 스핀마다 $\pm 5\%$의 동적 랜덤 변동치가 부여됩니다.

### 4.1 보너스 발생 빈도 순위 (내림차순)
1. **1위: 🍒 체리 2개 라인** (~10.0%, 최고 빈도) -> 게이지 1회 누적 (5회 누적 시 5회 보너스)
2. **2위: 🍒 체리 3개 라인 일치** (~7.5%) -> $5 + 1회 무료 보너스 롤
3. **3위: 🟩 1-BAR 3개 일치** (~5.5%) -> $50 + 1-BAR 보너스 5회
4. **4위: 🔔 종 (Bell) 3개 일치** (~4.0%) -> $30 + 종 보너스 5회
5. **5위: 🍓 ALL FRUITS** (~1.56% ~ 2.0%) -> $500 + 1회 무료 롤
6. **6위: 7️⃣ 7 3개 라인 일치** (~1.0%) -> $500 + 1회 보너스 롤
7. **7위: 💎 777 3개 라인 일치** (~0.5%, 최저 빈도) -> $750 + 1회 보너스 롤

### 4.2 매 스핀 $\pm 5\%$ 동적 지터 (Dynamic Fluctuation)
- 매 스핀(`getRandomSymbol`)마다 기준 심볼 가중치에 $0.95 \sim 1.05$의 난수를 곱하여 적용함으로써 매 회차 살아 숨쉬는 유기적인 당첨 주기를 제공합니다.

## 5. 🃏 5단계 포커 카드 더블찬스 (High & Low Double Up System)

슬롯에서 점수를 획득했을 때 플레이어가 도전할 수 있는 5단계 하이로우(High-Low) 미니게임입니다.

```text
┌────────────────────────────────────────┬────────────────────────────────────────┐
│     [화면 왼쪽: 5단계 스테이지 그림]     │      [화면 오른쪽: 포커 카드 대결]      │
│                                        │                                        │
│  Stage 1: 🥉 BRONZE (2x WIN)           │    [OPEN BASE CARD]    [HIDDEN TARGET] │
│  Stage 2: 🥈 SILVER (4x WIN)           │      ┌─────────┐         ┌─────────┐    │
│  Stage 3: 🥇 GOLD (8x WIN)             │      │  K ♥   │   VS    │    ?    │    │
│  Stage 4: 💎 DIAMOND (16x WIN)         │      └─────────┘         └─────────┘    │
│  Stage 5: 👑 ROYAL MASTER (32x MAX)    │   [▲ HIGH (8-K)]    [▼ LOW (A-6)]      │
│                                        │   [💰 TAKE SCORE]   [ESC EXIT]         │
└────────────────────────────────────────┴────────────────────────────────────────┘
```

1. **더블찬스 진입**:
   - 일반 스핀에서 점수를 획득하면 하단에 번쩍이는 **`[DOUBLE UP (D)]`** 버튼이 나타납니다.
   - `D` 키 또는 버튼을 누르면 획득한 당첨금을 판돈으로 더블찬스 화면으로 이동합니다.
2. **화면 구성**:
   - **왼쪽 화면**: 1단계(브론즈 2x)부터 5단계(로얄 마스터 32x)까지 성공할 때마다 일러스트가 변경되며 클리어 마크가 점등됩니다.
   - **오른쪽 화면**: `images/pokers/`의 52장 포커 카드 중 **오픈된 기준 카드(Base Card)**와 **뒤집힌 미스터리 카드(Hidden Target)**가 배치됩니다.
3. **하이로우 선택 및 승패 판정**:
   - **`HIGH` 선택**: 뒤집힌 카드가 **8, 9, 10, Jack, Queen, King (8 ~ 13)** 이면 승리!
   - **`LOW` 선택**: 뒤집힌 카드가 **Ace, 2, 3, 4, 5, 6 (1 ~ 6)** 이면 승리!
   - **`7` 출현 (TIE)**: 무승부로 판돈이 유지되며 새 카드로 재도전 기회 제공.
4. **성공 및 수령 후 복귀 (TAKE & EXIT) 메커니즘**:
   - **성공 시**: 상금이 **2배씩 증가**($X \times 2 \rightarrow 4 \rightarrow 8 \rightarrow 16 \rightarrow 32$)하며 경쾌한 레벨업 사운드(`playDoubleUpSuccess`)가 재생됩니다.
   - **언제든 점수 수령 후 복귀**: 플레이어는 끝까지 가지 않고 중간에 언제든 **`[💰 점수 수령 후 복귀 (ESC / T / Space)]`**를 눌러 현재까지 불어난 점수를 전액 안전하게 크레딧에 수령하고 본 게임으로 복귀할 수 있습니다.
   - **5단계 완승 시 (32배 MAX WIN)**: 울트라 잭팟 축하 팡파르와 함께 전액 수령 후 본 게임으로 멋지게 금의환향합니다.
5. **실패 시**:
   - 더블업 판돈이 전액 몰수되며, 아쉬운 다운톤 사운드(`playDoubleUpFail`)와 함께 본 게임으로 복귀합니다.

| :--- | :---: | :---: | :--- |
| **HIGH 선택** | `H` / `↑` | `[▲ HIGH]` | 다음 카드가 8~K(높음)에 베팅 |
| **LOW 선택** | `L` / `↓` | `[▼ LOW]` | 다음 카드가 A~6(낮음)에 베팅 |
| **점수 수령 (TAKE)** | `T` / `Space` / `Enter` | `[💰 TAKE SCORE]` | 현재 상금을 챙겨 본 게임 복귀 |
| **나가기 (취소)** | `ESC` | `[EXIT]` | 더블찬스를 종료하고 복귀 |

## 7. 🔊 사운드 시스템 명세 (`sound.js`)

외부 오디오 파일 없이 **Web Audio API 오실레이터(Oscillator)**를 통해 순수 코드로 구현된 정통 레트로 신디사이저 사운드:
- `playCoin()`: 맑고 영롱한 동전 땡그랑 소리 (Sine + Triangle 고주파 배음)
- `playSpinStart()`: 아케이드 릴 가속 구동음 (Sawtooth 상향 톤)
- `playReelStop()`: 기계식 릴 찰칵(Click) 안착음 (Triangle 저역 펄스)
- `playCherryCount()`: 체리 게이지 점등 띵동 사운드
- `playWin()`: 일반 라인 당첨 5단계 차임벨
- `playBonusFanfare()`: 보너스 진입 축하 멜로디
- `playJackpot()`: 올세븐/대박 잭팟 연타 팡파르
- `playCardFlip()`: 포커 카드 뒤집히는 찰나의 스냅음
- `playDoubleUpSuccess()`: 더블업 성공 2배 레벨업 승리음 (C-E-G-C-E 5음 상승 화음)
- `playDoubleUpFail()`: 더블업 실패 아쉬운 하강 톤 사운드
